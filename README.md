# AQUA-PULSE-WEB-APP

Frontend web application for visualizing AQUA-PULSE sensor data and managing device settings.

## Tech
- TypeScript, Vite, Tailwind CSS

## Quick start
```bash
npm install
npm run dev
```

## Notes
Integrates with the AQUA-PULSE backend / MQTT broker to display real-time metrics and alerts.
